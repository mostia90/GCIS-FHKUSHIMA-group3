# クイズ解説（Googleフォームの「回答に対するフィードバック」用）

各問題の解説は、下のコードブロックをそのまま貼り付けてください（GitHubではブロック右上のボタンでコピーできます）。

## 貼り付け方

```
① 編集画面で、クイズの問題をクリック
② 問題の左下にある「解答集を作成」をクリック
③ 「回答に対するフィードバックを追加」をクリック
④ 「不正解」タブと「正解」タブの両方に、同じ解説を貼り付けて「保存」
⑤ 「完了」をクリック
   → クイズ14問でくり返す（「何問正解したと思いますか」の2問には不要）
```

## スコア画面に解説を表示するための設定

| 設定（設定 → テスト） | 選ぶもの | 理由 |
|---|---|---|
| 成績の表示 | **送信直後** | 「手動で確認した後」を選ぶとメールアドレスの収集が自動でオンになり、匿名で回答してもらえなくなる |
| 回答者が表示できる項目 | **「不正解だった質問」「正解」「点数」をすべてオン** | オフのものがあると、解説や正解が表示されない場合がある |

設定後、**自分で1回テスト回答し、「スコアを表示」で解説が出るか確認**してください。
テスト回答は、本調査の前に「回答」タブから削除しておきましょう。

### 注意：送信後すぐに正解が見えるため

同じクラスで順番に回答してもらうと、先に終えた人から答えが広まるおそれがあります。

- できるだけ**一斉に回答**してもらう（授業やHRで同時に実施する）
- 完了メッセージに「正解と解説は、まだ回答していない人には教えないでください。」と一文足す
  （質問の中身は変わらないので、固定した版のデータには影響しません）

## 放射線（7問）

### 1. 経営母体（正解：東京電力）

```text
福島第一原発は東京電力の発電所で、ここでつくられた電気は福島県内ではなく、首都圏など東京電力の管内に送られていました。（東京電力ホールディングス）
```

### 2. 事故で実際に起きたこと（正解：電源を失って原子炉を冷やせなくなり、核燃料が溶け落ちた）

```text
地震で外部からの電源を、津波で非常用の電源を失い、原子炉を冷やせなくなって核燃料が溶け落ちました。原子炉建屋の爆発は発生した水素によるもので、核爆発ではありません。（資源エネルギー庁）
```

### 3. セシウム基準値の国際比較（正解：約10倍厳しい）

```text
日本の一般食品の基準値は1kgあたり100ベクレルで、国際的な基準（コーデックス委員会：1kgあたり1,000ベクレル）の10分の1、つまり約10倍厳しい値です。（厚生労働省）
```

### 4. 米の全量全袋検査（正解：0袋）

```text
福島県産米は2012年から全量全袋検査が行われ、2015年産以降、基準値（1kgあたり100ベクレル）を超えた米は1袋もありません。（福島県・環境省）
```

### 5. 帰還困難区域の面積（正解：約2〜3％）

```text
現在も避難指示が続いている帰還困難区域は、福島県全体の面積の約2.2%です。言いかえると、県の面積の約98%には避難指示が出ていません。（福島県）
```

### 6. 急性放射線症で亡くなった人（正解：いない）

```text
国連科学委員会（UNSCEAR）の報告でも、急性放射線症で亡くなった人は確認されていません。一方、避難生活の負担などによる震災関連死は、福島県で2,300人を超えています。（UNSCEAR・復興庁）
```

### 7. 除去土壌（正解：福島県外で最終処分する）

```text
除染で出た土は、大熊町・双葉町にまたがる中間貯蔵施設で保管されています。2045年3月までに福島県外で最終処分を完了することが、法律で定められています。（環境省）
```

## コロナ（7問）

### 8. 5類移行時の累計死者（正解：約7万5,000人）

```text
5類に移行した2023年5月8日時点で、国内の累計死者は74,669人でした。東日本大震災の死者・行方不明者（震災関連死を含め約2万2,000人）の3倍以上にあたります。（厚生労働省・警察庁・復興庁）
```

### 9. 感染経路の説明の変化（正解：当初は接触・飛沫感染が中心と説明されたが、後に空気感染（エアロゾル）の重要性が認められた）

```text
流行初期は手洗いや消毒など、接触・飛沫感染への対策が中心でした。その後、2021年にWHOがエアロゾル（空気中を漂う小さな粒子）による感染を認め、換気が重視されるようになりました。（WHO・国立感染症研究所）
```

### 10. 2022年末の2回接種率（正解：アメリカより10%以上高かった）

```text
2022年末の2回接種率は、日本が約8割、アメリカが約7割弱でした。接種の開始は日本の方が約2か月遅かったものの、最終的な接種率は日本が上回りました。（首相官邸・米国CDC）
```

### 11. 三密（正解：WHOが "Three Cs" として国際的に紹介した）

```text
「密閉・密集・密接」を避けるという日本発の考え方は、WHOも "Three Cs"（3つのC）として、世界に向けて呼びかけました。（WHO・厚生労働省）
```

### 12. トイレットペーパー不足（正解：国内生産が中心で在庫も十分あったが、誤情報による買い占めで一時的に店頭から消えた）

```text
日本のトイレットペーパーは約98%が国内生産で、在庫も十分ありました。「マスクと同じ原料で品薄になる」という誤った情報が広がり、買い占めで一時的に店頭から消えました。（日本家庭紙工業会）
```

### 13. ウイルスの起源（正解：自然由来説と研究所流出説の両方が議論されており、決着していない）

```text
WHOの専門家グループ（SAGO）は2025年6月の報告で、動物由来を示す証拠が多いとしつつも、研究所由来の可能性も否定できず、結論は出ていないとしています。（WHO）
```

### 14. インフルエンザとの致死率比較（正解：インフルエンザの約10〜20倍だった）

```text
流行初期は、新型コロナの致死率は1〜2%程度、季節性インフルエンザは約0.1%とされ、10〜20倍と説明されていました。比べ方で数字には幅があり、その後はワクチンの普及や変異株の変化などで大きく下がりました。（米国議会でのファウチ博士の証言など）
```
